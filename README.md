# TripWise — Embedded Insurance Intelligence Demo

TripWise is an end-to-end insurance telematics demo: it ingests driving telemetry,
scores drivers, serves those scores to an operational app, and lets agents act on them —
sending personalized, AI-generated offers and retention emails, with natural-language
analytics via Genie.

## Reference architecture (all six building blocks)

| Layer | Technology | Role in TripWise |
|-------|-----------|------------------|
| **Ingest** | Lakeflow Connect (Zerobus) | Stream synthetic driving telemetry into the lakehouse |
| **Govern** | Unity Catalog | Govern every table + the online catalog that fronts the operational DB |
| **Operational serving** | Lakebase (Postgres) | Low-latency reads for the app: device registrations, driver scores, location aggregates |
| **Intelligence** | ML + Gen AI | XGBoost premium/discount model (served endpoint) + LLM-generated emails |
| **Natural language** | Genie | Ask business questions of the data in plain English |
| **Experience** | Databricks App | Flask app surfacing analytics, offers, agent actions, and registrations to the business |

## Flow
Synthetic telemetry → **Zerobus ingest** → **Delta (Unity Catalog)** →
**ML training + serving** and **Gen AI** → **Lakebase** operational serving →
**Databricks App** (with embedded **Genie**) for the business user.
